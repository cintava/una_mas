# 🎰 UNA MÁS

App interactivo de demo para flujo de juego responsable en VR.

## 🎮 Características

- Selección de límites (fichas y tiempo)
- Timer en vivo con pausa automática
- Simulación de rondas (ganar/perder fichas)
- Reinicio en cualquier momento
- Estética casino profesional con animaciones

## 🚀 Cómo usar

**Opción 1 (Recomendado - sin descargar):**
Abrí directamente en el navegador: [app-una-mas.html](https://cintava.github.io/una_mas/app-una-mas.html)

**Opción 2:**
Descargá `app-una-mas.html` y abrilo localmente en cualquier navegador.

## 📋 Instrucciones

1. Selecciona cantidad de fichas (3, 5 o 7)
2. Selecciona tiempo de juego (3, 5 o 7 minutos)
3. Clickea "ARRANCAR JUEGO"
4. En cada ronda: clickea GANÉ o PERDÍ
5. El tiempo se pausa automáticamente
6. Clickea CONTINUAR JUGANDO o REINICIAR
